# Kishan M. Patil - Developer Portfolio (kishanm.me)

Official developer portfolio and interactive showcase of **Kishan M. Patil**, Frontend Specialist, Creative Developer, and AI Enthusiast.

🌐 **Live Website**: [https://kishanm.me](https://kishanm.me)

---

## 🛠️ Tech Stack & Architecture
- **Framework**: Next.js 16 (App Router, Turbopack, Static Export)
- **Styling**: Tailwind CSS & Lucide Icons
- **Graphics & 3D**: Three.js & WebGL
- **Agent Readiness & Protocols**: RFC 8288 Link headers, RFC 9727 API Catalog, RFC 9728 OAuth Protected Resource Metadata, Agentic Resource Discovery (ARD), Agentic Commerce Protocol (ACP), and Markdown Content Negotiation.

---

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

---

## 📦 Build & Export

```bash
# Generate static export (out directory)
npm run build
```
